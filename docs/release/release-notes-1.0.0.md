# OnlyTechTake - Release Notes v1.0.0 (Baseline)

Prima release pubblica ufficiale di OnlyTechTake.

## Novità principali
- **Gestione Commesse Locale**: Ciclo completo di accettazione, diagnosi, lavorazione e ritiro.
- **Privacy Local-First**: Tutti i dati risiedono sul dispositivo (database SQLCipher cifrato).
- **Documentazione Tecnica**: Supporto per foto, video e firme digitali integrate nelle commesse.
- **Esportazione PDF/XLSX**: Generazione istantanea di report e fogli di calcolo per la gestione operativa.
- **WhatsApp Integration**: Invio manuale di aggiornamenti di stato ai clienti tramite template personalizzabili.
- **Backup ZIP**: Esportazione e ripristino dell'intero ambiente di lavoro (solo versione Pro).

## Note tecniche
- Target SDK: 37 (Android 15)
- Min SDK: 26 (Android 8.0)
- Lingue supportate: Italiano, Inglese (Default)

## Limitazioni note
- Il ripristino di un backup tra dispositivi diversi potrebbe richiedere la stessa versione dell'App e del database.
- La condivisione WhatsApp è manuale e richiede l'app WhatsApp installata sul dispositivo.
