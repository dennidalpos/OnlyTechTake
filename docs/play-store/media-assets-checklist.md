# Media Assets Checklist

Assets required for Google Play Store publication.

## 1. Icona App
- [ ] **Dimensioni:** 512 x 512 px.
- [ ] **Formato:** PNG a 32 bit.
- [ ] **Peso max:** 1 MB.
- [ ] **Naming consigliato:** `icon_512.png`.

## 2. Immagine Coordinata (Feature Graphic)
- [ ] **Dimensioni:** 1024 x 500 px.
- [ ] **Formato:** JPEG o PNG a 24 bit (senza trasparenza).
- [ ] **Contenuto:** Logo OnlyTechTake e un claim accattivante (es. "Il tuo laboratorio in tasca").
- [ ] **Naming consigliato:** `feature_graphic_1024x500.png`.

## 3. Screenshot Telefono
- [ ] **Quantità:** Minimo 2, consigliati 6-8.
- [ ] **Rapporto aspetto:** 16:9 o 9:16 (minimo 320 px, massimo 3840 px).
- [ ] **Naming consigliato:** `phone_01_dashboard.png`, `phone_02_new_order.png`, ecc.

## 4. Screenshot Tablet (Opzionale ma consigliato)
- [ ] **Dimensioni 7 pollici:** Almeno 4 screenshot.
- [ ] **Dimensioni 10 pollici:** Almeno 4 screenshot.

## 5. Video Demo (Opzionale)
- [ ] **Formato:** Link YouTube.
- [ ] **Durata:** 30-45 secondi.
- [ ] **Orientamento:** Verticale (9:16) consigliato per mobile.

## Linee guida per la privacy negli asset
Per superare la revisione e rispettare la privacy, negli screenshot e nei video **NON** mostrare mai:
- [ ] Nomi e cognomi di persone reali.
- [ ] Numeri di telefono reali.
- [ ] Indirizzi email o fisici reali.
- [ ] Codici fiscali o Partite IVA reali.
- [ ] Firme autografe reali.
- [ ] Foto di persone o di proprietà private riconoscibili.

**Suggerimento:** Usa dati demo come "Mario Rossi", "Via Roma 1", "555-0101", ecc.
