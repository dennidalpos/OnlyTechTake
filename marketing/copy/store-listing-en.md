# Store Listing - English

## OnlyTechTake Pro

**App Name:** OnlyTechTake: Repair Management Pro
**Short Description:** Local management solution for smartphone and PC repair labs.
**Full Description:**
OnlyTechTake is a tool for managing the workflow in repair shops. It allows you to track the entire lifecycle of repair orders directly from your Android device.

Data Security
All data is stored locally on the device. The application uses an SQLCipher encrypted database and operates offline, ensuring that customer and repair information remains private.

Features:
- Order Management: track repair stages (Open, Diagnosis, In Progress, Ready, Closed).
- Customer Registry: manage contacts and repair history in a local database.
- Digital Signature: capture acceptance signatures directly on the screen.
- Photo Documentation: attach photos of device conditions.
- Communication: prepare messages for manual sending via messaging apps.
- PDF Reports: generate intake forms and receipts in PDF format.
- Export & Backup: export data to XLSX format and create encrypted ZIP backups.

The application is designed to provide an organized workflow for repair professionals, with no cloud subscriptions or external servers required.

## OnlyTechTake Demo

**App Name:** OnlyTechTake: Repair Trial
**Short Description:** Trial version of the OnlyTechTake repair management workflow.
**Full Description:**
OnlyTechTake Demo allows you to test the basic features of the repair management system before purchasing the full version.

Demo Version Limitations:
