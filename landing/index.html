Build locali

La landing non pubblica APK e non punta a Play Store. Generare gli installer dal repository con gli script PowerShell documentati.

powershell -ExecutionPolicy Bypass -File scripts\android\build_installer.ps1 -Flavor Full -BuildType Debug -OutputType Apk

Nota: le build release richiedono `keystore.properties` locale non tracciato.
