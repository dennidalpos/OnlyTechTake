# OnlyTechTake — Feature Icon Pack

Pacchetto icone vettoriali per sostituire le icone feature dell'app Android e della landing page.

## Contenuto

- `svg/`: SVG 64x64 per landing page, web, marketing card e componenti HTML.
- `android_vector_drawable/`: XML Android VectorDrawable 64dp / viewport 64 per `app/src/main/res/drawable`.

## Palette

- Teal: `#00B6B0`
- White: `#F5F2EA`
- Mustard: `#FFB627`
- Charcoal: `#0D0D0D`

## Mapping consigliato landing page

Sostituisci le feature Lucide attuali così:

- Service Workbench / Intake: `feature_intake.svg` oppure `ic_feature_intake.xml`
- Workflow Tracking / Stati: `feature_workflow_tracking.svg` oppure `ic_feature_workflow_tracking.xml`
- Customer Updates: `feature_customer_updates.svg` oppure `ic_feature_customer_updates.xml`
- Media Documentation: `feature_media_documentation.svg` oppure `ic_feature_media_documentation.xml`
- Signature & Privacy: `feature_signature_privacy.svg` oppure `ic_feature_signature_privacy.xml`
- Secure Local Backup: `feature_secure_local_backup.svg` oppure `ic_feature_secure_local_backup.xml`

## Note pratiche

Gli SVG usano stroke arrotondati e fill flat, quindi sono facili da colorare via CSS se vuoi una versione monocromatica. Gli XML Android non usano CSS e sono compatibili con VectorDrawable.
